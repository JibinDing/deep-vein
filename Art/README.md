# Art Drop Folder

Put incoming art assets here before we wire them into Godot.

## Folders

- `tiles/` - 64x64 map tiles and tilesets.
- `ui/` - HUD icons, inventory icons, buttons, panels.
- `references/` - mood boards, sketches, previews, notes.
